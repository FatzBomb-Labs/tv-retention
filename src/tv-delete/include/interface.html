How a rule decides

A rule may set any combination of keep days, keep episodes, and keep seasons. Each condition votes on every episode, and the combine mode settles disagreements.

Combine modeMeaningEffect
EarliestAn episode survives if any condition keeps it.Keeps the most. The safe default.
LatestAn episode is deleted only if every condition says so, and none was undecidable.Keeps the least, without ever acting on an unknown.
AnyAn episode is deleted if any condition says so.Most aggressive. Ignores conditions it cannot judge.

What is never deleted

  • Anything under a rule that is not matched to exactly one Sonarr series.
  • Media files Sonarr does not know about — they are listed in the run report instead.
  • Specials (season 0), unless you turn them on.
  • Files modified inside the minimum age window.
  • Everything, when dry run is on, or when a guard stops the run.

Air dates

Sonarr's air date is used first, then TMDB if enabled, then the file's modification time. The source of each date is shown in every preview, so you can see when a decision rests on a file timestamp rather than a real air date.
